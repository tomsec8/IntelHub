Privacy Policy – IntelHub

Effective Date: June 25, 2026

IntelHub is an Open Source Intelligence (OSINT) workstation extension designed to help researchers aggregate public tools. Because we serve the investigative community, transparency regarding data transmission is our highest priority.

1. Data Collection & Processing

IntelHub does not actively collect, record, or track your personal data, browsing history, or analytics. The extension operates locally on your machine. However, to provide OSINT functionalities, specific features intentionally transmit user-provided data (e.g., URLs, usernames, or images) to specific third-party services as detailed below.

Local Processing: Features like Metadata Extraction (EXIF, PDF, Office) and File Hashing are performed strictly locally on your device without communicating with any external servers.

2. Third-Party Data Transmission

If you choose to use the following specific features, IntelHub will transmit your input to the corresponding third-party services:

  • Reverse Image Search: If you paste an image URL that is already public, IntelHub opens the selected engines with that URL and does not upload the file. If you upload or paste a local image, it is posted to a public file host (catbox.moe) — not a proxy — so Google, Yandex, Bing, and TinEye can fetch it. Catbox can see the file and usually your IP; the link is public and may remain after the search. Consent is required before a local image leaves the device.
  • Short Link Tracer: In the Workspace Web tools, the extension follows a shortened or redirected URL locally and records each hop until the final destination. No third-party proxy or external URL unshortener is used.
  • IP Lookup: In the Workspace Web tools, an IP address or hostname you submit is sent to ip-api.com (HTTP JSON API) to retrieve geolocation, ISP, ASN, and proxy/hosting flags. Empty queries send your current public IP as seen by that service. Rate-limited to 45 requests per minute by ip-api. The same IP is also queried via RDAP (rdap.org, which redirects to the relevant RIR such as ARIN, RIPE, APNIC, LACNIC, or AFRINIC) for allocation, CIDR, and abuse contacts. An AbuseIPDB button opens their public check page in a new tab; IntelHub does not call the AbuseIPDB API and does not use an API key.
  • DNS & OSINT Lookups: Resolving IP addresses relies on the Google DoH API (dns.google). Domain Lookup also queries rdap.org (and the registry it redirects to, commonly Verisign for .com/.net) for registrar and registration dates. Subdomain Finder queries public datasets with the target domain: Certificate Transparency (crt.sh, Cert Spotter), the Wayback Machine CDX API, AlienVault OTX passive DNS, Anubis, HackerTarget, and urlscan.io. A subset of discovered names is then resolved via Google DoH. Other investigation buttons open new tabs to third-party services (e.g., VirusTotal, W3Techs, WHOIS) with the target domain as a URL parameter.
  • Crypto lookups: The Workspace Crypto tool sends Bitcoin addresses (and Bitcoin transaction IDs pasted in the same box) to blockchain.info (Blockchain Data API: rawaddr, rawtx, unspent, balance) to retrieve balances, transfers, UTXOs, and transaction details. Ethereum addresses and 0x transaction hashes are sent to api.ethplorer.io (Ethplorer, public freekey) for ETH balance, token holdings, and recent transfers, with eth.blockscout.com as a fallback. Address type detection is performed locally. Other chains and Bitcoin testnet addresses are not queried live.
  • Email lookups: Breach lookup sends an email you submit to api.xposedornot.com. Infostealer lookup sends an email, username, or domain to Hudson Rock's free Cavalier API (cavalier.hudsonrock.com). Gravatar lookup hashes the email locally with SHA-256 and requests the public profile/avatar from gravatar.com. None of these features use an API key. Results stay in this browser unless you copy them elsewhere.
  • OSINT Tools catalog: The extension occasionally fetches the public awesome-osint list from raw.githubusercontent.com (jivoi/awesome-osint, CC BY-SA 4.0) to populate tool categories. No personal data is sent in that request.

3. Permissions Explanation

  • activeTab: Used to detect the currently active tab when the user explicitly clicks features like "Save Page Offline" or "Site Analyzer."
  • storage & unlimitedStorage: Used to save user preferences, custom graph nodes, and UI configurations locally in your browser.
  • scripting: Required to inject scripts into pages when you explicitly run features such as Google ID Scanner, Social ID Extractor, Site Analyzer, and Telegram tools.
  • downloads: Used exclusively to save generated reports, graphs, or offline evidence HTML files directly to your local machine.
