Privacy policy

What leaves the browser

Effective June 25, 2026

IntelHub does not collect, record, or track personal data, browsing history, or analytics. It runs on your machine. A tool sends only the value you submit, and only when you run it.

Stays on this device

Metadata, hashing, encryption, text profiling, and Telegram or Funstat analysis are local.

Sent only when you run the tool

  • Reverse image search. A public image URL is opened in the engines you pick. A local image is posted to catbox.moe so those engines can fetch it. Consent is required before a local image leaves the device.
  • Short link tracer. Hops are followed on your machine. No unshortener service is used.
  • IP lookup. The address goes to ip-api.com and RDAP. AbuseIPDB is only a link.
  • DNS and domains. Resolution uses Google DNS-over-HTTPS. Registration data comes from rdap.org. Subdomain search queries public certificate, archive, and passive-DNS sources.
  • Wallets. Bitcoin goes to blockchain.info. Ethereum goes to api.ethplorer.io, then eth.blockscout.com if needed.
  • Email lookups. Breaches go to api.xposedornot.com. Infostealers go to cavalier.hudsonrock.com. Gravatar hashes the email locally and requests the public profile.
  • OSINT catalog. The public awesome-osint list is sometimes downloaded from GitHub. That request has no personal data.

Permissions

  • activeTab reads the tab you are on when you start a page tool.
  • storage keeps preferences and investigations in this browser.
  • scripting reads a page only after you start a tool that needs it.
  • downloads saves files you export.
